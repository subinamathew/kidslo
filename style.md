# Echo Kids Website – Design System Rules (Antigravity)

Follow these strict brand guidelines when designing and building the **echo kids** website[cite: 7].

## 1. Brand Colors
Use only the official Echo Kirche color palette[cite: 17]:

* **Primary / Dark Teal Blue (`#08415C`)**: Use for primary headings, body text, logos, and dark UI accents[cite: 17].
  * RGB: `8, 65, 92`[cite: 17]
* **Secondary / Muted Lavender (`#846B8A`)**: Use for secondary text, highlights, buttons/accents, and logo variations[cite: 17].
  * RGB: `132, 107, 138`[cite: 17]
* **Background / Light Pastel Yellow (`#FEFADC`)**: Use for soft page backgrounds, section surfaces, and warm accents[cite: 17].
  * RGB: `254, 250, 220`[cite: 17]

*(Note: High-contrast black and white may also be used for inverted logo applications[cite: 5, 6].)*

---

## 2. Typography & Font Families
* **Headings & Sub-brand Wordmark**: `Clash Display` (Weight: `600` / Semibold)[cite: 4, 12]
  * *Logo formatting note*: When displaying the sub-brand text logo, **echo** is set in `Clash Display Semibold` and **kids** is set in `Clash Display Regular` (`400`)[cite: 4, 7].
* **Body & UI Text**: `Inter` (Weight: `400` / Regular)[cite: 12]
* **Optional Digital Accent Fonts** (for special banners, callouts, or magazine-style sections)[cite: 13]:
  * Display/Headline Accent: `Perandory Condensed`[cite: 13]
  * Script/Subheading Accent: `Sloop Script Pro`[cite: 13]

## 4. Logo & Media Rules
* **Logo Clear Space**: Maintain a minimum clear space equal to the width/height of the lowercase letter **"e"** from the logo on all four sides[cite: 10]. Never stretch, rotate, distort, or recolor the logo outside approved brand colors[cite: 8].
* **Web Images**: Use `.webp` format (`max 400KB`), `1900px` max width for hero images, and `1400px` max width for standard images (`3:2`, `4:3`, or `16:9` aspect ratios)[cite: 9].
